# PRD: AI Sales Bot (NLP-Enhanced Closing Machine)

## Overview
An AI sales agent with the same "brain" architecture as the Practitioner Bot (PRD-03), but constrained as a professional closer rather than a clinical practitioner. Loaded with elite sales training (Jerry Minor, etc.), NLP meta-programs, and persuasion frameworks. The most advanced AI sales system ever built — because it doesn't just follow a script, it reads the prospect's communication patterns and adapts in real-time using NLP.

## How It Differs From the Practitioner Bot

| Aspect | Practitioner Bot | Sales Bot |
|--------|-----------------|-----------|
| **Goal** | Help client resolve an issue | Close the prospect on a deal |
| **Constraint** | Clinical practitioner boundaries | Professional sales ethics |
| **Interaction** | Appointment-based sessions | Conversational (chat, call, email) |
| **Tone** | Empathetic, calm, therapeutic | Confident, energetic, persuasive |
| **Protocol** | Technique procedures | Sales frameworks & closing sequences |
| **State** | Session history, intensity logs | Pipeline stage, objections, follow-ups |
| **NLP Usage** | Therapeutic techniques | Meta-programs, rapport, language patterns |

## The Brain (Same Architecture, Different Loading)

### Protocol Files for Sales
Instead of EFT tapping protocols, the sales bot loads:

```markdown
# Discovery Call Protocol

## Phase 1: Rapport (2-3 min)
- Mirror prospect's communication style
- Identify meta-programs (toward/away, internal/external, options/procedures)
- Match language patterns

## Phase 2: Pain Discovery (5-7 min)
- Ask: "What's the biggest challenge you're facing with [area]?"
- Go 3 levels deep: "And what does that cost you?" → "What happens if nothing changes?"
- Store: {pain_points}, {cost_of_inaction}, {emotional_drivers}

## Phase 3: Vision (3-5 min)
- Ask: "If this was solved, what would that look like?"
- Amplify: "And what would THAT mean for you/your business/your family?"
- Store: {desired_outcome}, {emotional_payoff}

## Phase 4: Present Solution (3-5 min)
- Bridge pain to solution
- Use prospect's own language (mirroring)
- Address only the pain points they mentioned
- Social proof matched to their situation

## Phase 5: Handle Objections
- If "too expensive": → reframe against cost of inaction
- If "need to think about it": → identify what specifically they need to think about
- If "need to talk to partner": → schedule 3-way call
- If "not the right time": → what would make it the right time?

## Phase 6: Close
- Assumptive close: "So should we get you started with [option A] or [option B]?"
- If hesitation: → return to pain, re-amplify
- If no: → graceful exit + follow-up sequence
```

### NLP Meta-Programs Integration
This is the secret weapon. Meta-programs are the unconscious filters people use to process information. The sales bot detects them from conversation patterns and adapts:

**Toward vs. Away From:**
- Toward: Motivated by gains, goals, achievements → "Imagine what you'll achieve..."
- Away From: Motivated by avoiding pain, problems → "You'll never have to deal with..."
- Detection: Listen for "I want to gain..." vs. "I want to stop losing..."

**Internal vs. External Reference:**
- Internal: Trusts own judgment → "You'll know this is right when you see the results yourself"
- External: Needs validation → "Here's what 500 other customers say..."

**Options vs. Procedures:**
- Options: Wants choices, flexibility → "You have three paths forward..."
- Procedures: Wants step-by-step → "Here's exactly what happens next: Step 1..."

**General vs. Specific:**
- General: Big picture first → "The bottom line is..."
- Specific: Wants details → "Let me walk you through each feature..."

**Proactive vs. Reactive:**
- Proactive: Ready to act → "Let's get started right now"
- Reactive: Needs to analyze → "Take your time, here's everything you need to evaluate this"

The bot detects these in real-time and adjusts its language, framing, and closing approach.

## Deployment Modes

### Mode 1: Live Chat Closer
- Embedded on website/landing page
- Real-time text conversation
- Handles inbound leads 24/7
- Can qualify, nurture, and close
- Escalates to human for complex deals

### Mode 2: Voice Sales Agent
- Handles outbound/inbound phone calls
- Real-time voice with NLP adaptation
- Full discovery → close call flow
- Transfers to human when needed

### Mode 3: Email/DM Nurture
- Follows up with leads over days/weeks
- Personalized sequences based on meta-program profile
- Re-engages cold leads with tailored messaging
- Books calls when prospect is warm

### Mode 4: Sales Training Simulator
- Role-plays prospect for sales team practice
- Throws realistic objections
- Scores performance
- Gives NLP-based feedback
