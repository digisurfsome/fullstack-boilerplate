# PRD: Unified Product Vision — The Transformation Platform

## The Big Picture
A platform of interconnected apps and bots, all sharing the same core "brain" architecture but loaded with different protocols, knowledge bases, and constraints. Each product is a different expression of the same underlying system: AI agents that follow structured protocols to guide humans through transformation processes.

## Product Family

### 1. Visualization & Manifestation App (PRD-01)
**What:** AI-generated personalized success visualizations + NLP submodality work + guided meditation
**For:** Anyone wanting to manifest health, wealth, or life goals
**Unique:** Text-to-video of YOU in your success state, matched to your neural modality profile

### 2. Diet & Craving Elimination App (PRD-02)
**What:** NLP dislike/like swap for food cravings, integrated with keto grocery scanner
**For:** Anyone on a diet who can't stop craving certain foods
**Unique:** "The NLP alternative to Ozempic" — reversible, drug-free, diet-agnostic

### 3. AI Practitioner Bot (PRD-03)
**What:** Voice/chat AI that leads clinical-style NLP, EFT, and hypnosis sessions
**For:** Anyone wanting affordable access to transformation techniques
**Unique:** Protocol-driven agent with session state — not a chatbot, a practitioner

### 4. AI Sales Bot (PRD-04)
**What:** NLP-enhanced sales agent that reads meta-programs and adapts in real-time
**For:** Businesses wanting 24/7 AI closers, sales trainers wanting to productize
**Unique:** Meta-program detection + elite sales training = superhuman closer

## Shared Infrastructure

### The Brain Architecture (shared across all products)
```
Protocol Files (.md) → Agent Core (LLM) → Session State Store → Voice/Chat Interface
```
- Same pattern everywhere: load different protocols, get different practitioner/bot
- Session state management is universal
- Voice interface is universal
- Only the CONTENT changes

### Submodality Engine (shared between PRD-01, PRD-02, PRD-03)
- One profiling module, used everywhere
- User does it once, profile travels across products
- Positive and negative neural signatures

### AI Visualization Pipeline (PRD-01, extendable)
- Text-to-image/video generation
- Face integration
- Modality-matched rendering
- Storyboard assembly

## The Mixing Principle
The core insight: individual NLP techniques are powerful, but MIXING them together multiplied the effect. The platform is designed for mixing:
- Submodality profiling + dislike swap + AI visualization = most powerful craving elimination
- EFT tapping + submodality work + guided meditation = deepest emotional clearing
- Meta-program reading + sales frameworks + NLP rapport = most effective sales
- Visualization + emotional conditioning + scramble pattern = fastest manifestation

No single app or practitioner currently combines these. That's the moat.
